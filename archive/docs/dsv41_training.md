# DeepSeek-V4.1-Flash 训练过程如实整理

来源： arXiv 2609.19969v1 正文（`ref/deepseek/v41_text.txt`），只收录原文写明的数字与流程，无推测。
配套流水线实现： `dsv41/train.py`（按本文档的优化器方案与两阶段长度扩展实现，缩放到 6G 显存）。

## 一、预训练

### 1. 数据（§4.1）
- **45T 多模态 token**，全程无不稳定。
- 文本： 系统化/标准化的数据构造流水线；按"模型参数 × 训练数据"设计 scaling ladder 指导大规模训练；
  过滤**低信息增益的模型生成内容**（弱模型输出、低质机翻）——视为**隐性重复**；
  模型在环的数据迭代；领域专家参与细粒度质量维度；纳入新开源仓库/提交/库/新框架的近期代码。
- 多模态： 图文对、交错图文、领域数据三类；**不做大规模合成**，以原生形态清洗使用。
- 多模态数据**从语言模型预训练一开始就混入**（§2.1）。

### 2. 优化器（§2.5 + §4.2.2）
| 参数类别 | 优化器 | 超参 |
|---|---|---|
| 线性变换权重 | **Muon** | 动量 0.95，weight decay 0.1，更新矩阵 RMS rescale 到 **0.18**（复用 AdamW 学习率） |
| **Q/K 权重** | **head-wise Muon**（按头拆开再更新） | 同上 |
| RMSNorm 与非矩阵参数（偏置/缩放） | **AdamW** | β₁=0.9, β₂=0.95, ε=10⁻²⁰, wd=0.1 |
| **嵌入 / 预测头 / Engram** | **Sinkhorn 平衡的动量更新**（Alg.1） | 动量 0.95、γ=0.18、K=11、τ=10⁻³、ε=10⁻²⁰；**无 weight decay**；Nesterov |
- Muon 用解耦 weight decay + Nesterov 动量；**归一化层权重也做 weight decay**，偏置与缩放不做。
- **Engram 学习率 ×5**。
- Sinkhorn 平衡 = 对更新矩阵做交替行/列归一化（K 步、奇数步归一行），近似把行/列 RMS 都拉到 1，
  再乘 √n 与 γ；近零行（ρᵢ ≤ τ·ρ̄）先掩掉。

### 3. 训练超参（§4.2.2）
- **批大小恒定 100.6M token**。
- 学习率： 前 **2000 步线性 warmup** → **2.6e-4 恒定到 28T** → **28T~40T 余弦衰减到 2.6e-5** → **40T~45T 恒定**。
- **序列长度两阶段： 从头以 64K + 稀疏注意力训练，34T token 时扩展到 1M**。
- MoE 负载均衡（§2.1.1）： auxiliary-loss-free，**偏置更新速度 0.001**（图文各自独立），
  另保留**序列级平衡损失，权重 1e-4** 防单序列内极端不均。
- **sample-level attention masking**（按样本隔离注意力，同 DeepSeek-V4）。
- 视觉编码器（§4.2.2）： 先单独两阶段训练——对比预训练（SigLIP sigmoid 损失，约 **47B 图文对**，
  最大 224×224）+ 自回归微调；语言预训练期间**冻结**，只训其 final norm 与视觉-语言 projector，
  **LR 衰减开始时**才解冻并用更小学习率联合训练。
- **预训练不带 MTP 模块**（§2.1）；**DSpark 在预训练后单独一阶段训练（骨干冻结）**（§2.4.3）。

### 4. CSA2/Engram 的训练基建（§3.1.2/§3.1.3）
- 共享参数跨流水线阶段的三个机制： **shadow indexer**（每阶段放轻量副本，单一逻辑属主负责优化与存档）、
  **pipeline payload 扩展**（把中间表示与稀疏路由随点对点通信传给下游）、
  **微批级共享状态管理**（跟踪并发微批的共享状态生命周期，最后一个消费者完成才释放）。

## 二、后训练（§5.1）

- **明确声明：不引入新的后训练算法**。配方 = **SFT → RL → OPD（在线策略蒸馏）** 的标准范式。
- 全部投入在"**训什么**"而非"怎么优化"：
  (i) 大规模合成**可验证**任务（带参考解与奖励信号）；
  (ii) 程序化构建与规模化**交互式 agent 环境**（轨迹可低成本收集与评估）；
  (iii) 严格过滤、去重、**难度校准**保证数据质量与课程均衡。
- 结论性表述： 固定平凡的优化流程下，合成数据与环境在**规模、多样性、可验证性**上的系统性提升
  贡献了几乎全部增益——"数据与环境流水线的边际回报远大于算法新颖性"。
- 任务形式化为三元组 **(问题, 环境, 验证系统)**，质量两维度 = **难度**（非平凡）与**正确性**（三组件无关键缺陷）；
  用这两个维度当奖励**迭代训练模型的造任务能力**；任务被新 RL 轮复用时，产生的轨迹回流做质量再审计。
- 通用 agent： 员工/合作伙伴把模型嵌入日常工作流，自愿回流交互数据；据此构建 **mock 工具**复现真实工具的接口与行为。
- 可控推理努力（§5.1.4 + 附录C）： RL 中用**指数 token 惩罚**控制推理预算。
- 异步后训练基建（§5.2）： 缓解**长度偏差**与 **off-policy 效应**；规模化在线策略蒸馏。
- DSpark 在后训练期继续与骨干联合训练，但 **DSpark 目标不向骨干回传梯度**（§2.4.3）。

## 三、我们流水线的对应缩放（dsv41/train.py）

| 论文 | 我们的实现（6G 显存） |
|---|---|
| 45T token / 100.6M 批 | 合成长上下文任务，批 ~0.5M token |
| Muon + head-wise Muon + AdamW + Sinkhorn | **全部照抄**（Newton-Schulz5 / Alg.1 逐行实现） |
| Engram lr ×5 | 同 |
| warmup 2000 步 → 恒 → 余弦衰减 → 恒 | 同形状（步数等比缩） |
| 64K → 1M（34T 处扩展） | **4K → 32K（中途扩展）** |
| 序列级平衡损失 1e-4 + 偏置 0.001 | 同 |
| sample-level masking | 同（按样本隔离） |

> 未实现（如实声明）： 视觉塔（SigLIP 对比预训练）、DSpark 独立训练阶段、RL/OPD 全流程、
> 分布式基建（shadow indexer 等单机不需要）。
## 四、流水线实测（dsv41/train.py，本机 6G 显存）

| 项 | 实测 |
|---|---|
| 显存 | 训练 **1.5–1.7 GB**；RSS 1.9 GB（远在 6G 内） |
| 两阶段 | 阶段A seq=1024 × 300 步 → 阶段B seq=2048 × 60 步 |
| loss | **8.59 → 4.15**（≈ln 64 = 4.16 ⇒ 已学会把答案限定在 64 个候选词内） |
| 查中率 | **0.000**（4096 词表上的严格 top-1；尚未打通"定位 key → 读 value"的检索回路） |
| 优化器 | Muon / head-wise Muon / AdamW / Sinkhorn(Engram×5) 全部生效，无 NaN |

### 建流水线时修掉的三个真错
1. **Newton-Schulz 系数发**散：我凭记忆写的 `(3.4445, -4.4752, 2.7910)` 三项和为 1.76 ≠ 1
   ⇒ `f(σ)=aσ+bσ³+cσ⁵` 在 σ=1 处**不动点不存在** ⇒ **一步就把全部 283 个参数打成 NaN**。
   数值解出收敛系数 **`(2.7, -2.9, 1.2)`**（实测 5 步后奇异值落在 [0.989, 1.022]）。
2. **Engram 参数被同时注册进两个优化器**（基础 lr 与 ×5 桶）⇒ 同一参数更新两次。改为互斥分桶。
3. **Block 不是纯函数**（复用状态 `_st`/`_nc` 与 mHC 的 `prev_a` 写在模块属性上）
   ⇒ 梯度检查点重算对不上（"different number of tensors saved"），且跨批次残留会报
   "backward through the graph a second time"。改成**状态显式进出**后检查点才可用。

### 已知限制（如实声明）
- **稀疏注意力对全 `(L, n_ent)` 打分后掩码**（便于逐项对齐论文语义），长度 ×2 时工作区 ×4。
  评测因此上限定在 2× 训练长度。论文 1M 上下文靠的是**在线 softmax 的 Top-K 稀疏核**（不物化全打分）——
  这是本实现与论文工程实现之间的差距。
- **swa_only 层已按 §2.1 修**（前两层"只有 SWA"，不是"没有注意力"）。
- 未实现：视觉塔、DSpark 独立训练阶段、RL/OPD、分布式基建（shadow indexer 等单机不需要）。
