## 1–2. 目标与设计原则
目标：显式抽象语法 / 稀疏条件计算 / 可微 / 可解释 / 高性能 / 可扩展。
原则：规则隐式连续 · 触发稀疏 · 位置精确(RoPE) · 冲突加权 · 残差捷径 · 梯度训练 · 混合注意力 ·
**线性化**（不物化 (B,H,L,L)） · **窗口恒定** · **低秩门控** · **局部归一化** · **可失败性** · **撤回明说**。

## 3. 核心裁定（12 条）
| # | 张力/歧义 | 裁定 |
|---|---|---|
| 1 | 多哈希 O(1) vs 软读 O(N) | 多哈希只取候选槽，软读只在候选集内 |
| 2 | 哈希键取 token id 还是隐状态 | 取 **token id**；软读询问取可训练 n-gram 嵌入 |
| 3 | 规则向量如何影响位置 | 规则向量 → 相对位置分桶偏置 `B_k[bucket(i-j)]` |
| 4 | 门控形状不匹配 | `w_k` 逐维可学，`g_k=σ(w_k⊙v_k)` |
| 5 | 无触发是否零计算 | 规则/内容分开计数；全空槽时规则路径整体跳过 |
| 6 | 规则放 softmax 内还是残差直加 | **两条并存** |
| 7 | 尺度失配致规则被淹没 | 分桶剖面归一为零均值单位方差 × 可学 `rule_scale` |
| 8 | 窗口 W ∝ L ⇒ 仍 O(L²) | 窗口**固定常数** |
| 9 | 规则只喂 `topk().indices` ⇒ 零梯度 | 规则同时给硬选择 + **可微强度** |
| 10 | SwiGLU 无归一化 ⇒ 质量退化 | 窗口内逐通道局部归一化 `o=Σ(gate·up)/Σ|gate|` |
| 11 | 双峰成因不是窗口覆盖 | 窗口已必然覆盖中心词；成因是训练塌缩/不稳定 |
| 12 | 门归因诊断 | 动词位置比较门给中心词 vs 给吸引子的份额 |

## 4–5. 架构与模块
`嵌入+RoPE → [Engram 查找(n-gram 哈希→规则向量) → 规则桶偏置选桶 → 固定窗口 gather k,v →
低秩 SwiGLU 门控(Dg=16) → 窗口内局部归一化(O(W)) → 内容门控 gc=σ(W·h) → 残差+FFN] × N → 任务头`
- Engram：可微键值 `{(k_i,v_i)}`；键 = 3 个哈希（不同乘子+模数，作用于 token id 的 1..3 阶 n-gram）；
  值 = 连续规则向量；**软读只在候选集内**。
- 窗口：以**偏置最高的桶**为起点、长度恒为 `window_max` 的**连续**偏移区间（旧版"每桶各取冗余偏移"
  在 `step=1,per=4` 下桶 0-3 只覆盖偏移 0-6、漏掉距离 7 —— 由 C20 抓出）。
- 局部归一化：`o = Σ(gate·up)/Σ|gate|`，O(W) 而非 O(L)。

**8.4 修双峰（近端偏置+连续窗口）：假设被否**，0.4980→0.4633、极差 0.978→0.858，双峰照旧。

## 12. 结论

**★编者注（2026-10-09，实测更正，务必先读）**
原文此节把"ER 的吸引子干扰 0.0150–0.0335 vs 稠密 0.2806，小 8–19 倍"列为**第二条确证优势**。
