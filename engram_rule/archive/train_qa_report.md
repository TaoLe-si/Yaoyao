## 3. 答案开头按「留一频次」分层

LOO = 除它自己外，训练里还有多少行用同一个答案开头。
分层子集 n=819（`sub` 与 `loo` 同源，已断言）。

| 分层 | n | 首 token acc |
|---|---:|---:|
| LOO=0（只见 1 次） | 131 | 0.1832 |
| LOO=1 | 104 | 0.2981 |
| LOO 2–3 | 158 | 0.4557 |
| LOO≥4 | 426 | 0.7653 |

频次依赖斜率 **β = slope(命中率 ~ log(1+LOO)) = +0.2121**
⇒ 命中率**随这个开头被见过几次而上升**：这是"绑定存在，但低频学不会"的量化形状。
§48 证明 β 会随模型加宽被压到 0 附近（d=64 +0.2121 → d=256 −0.0012）。

## 5. 怎么读这份表

- **teacher-forced 分数高 ≠ 会生成。** token acc 0.7905、首 token acc 0.5524，
  但 greedy 生成完全匹配只有 2/12 —— 这是本项目的核心落差（§38 已记录 train 1/8），不是新问题。
- **「看问题」的净贡献**：全答案 +0.5672、首 token +0.5061（相对闭式基线）。
  Δtrain=+5.1735 是更直接的证据：恒等问题对照下它精确为 0。
- **低频开头是真弱项**：LOO=0 组首 token acc 0.1832 vs LOO≥4 组 0.7653，β=+0.2121。
  §48 已证明这是**容量受限**并被治好；但**eval 侧迁移率不随容量变**（§48）。

## 6. 诚实边界

- **单种子**（v11 = seed 11），**无种子极差**。
- 自由生成取的是**前 12 条原始顺序**，不是随机抽样；换一批样本结论可能变。
- B1–B4 都是**闭式**统计量，不是训练出来的 n-gram/LSTM ⇒ 是 floor 的**下界**，
  「模型比不看问题高多少」这个说法因此**偏保守**。
- 本文只报 **train 侧**。eval 侧的天花板见 DESIGN §49（无脑 floor 0.0833 / 0.1830）。
- 本脚本**不测**扩窗/加 Engram 等结构改动的影响（规则 17）。
