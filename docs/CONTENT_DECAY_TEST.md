# 内容相关衰减：冻结模型干预

本轮使用5个init2共享四token模型的既有权重，未重新训练，无边界oracle输入。原格式object-owner-delimiter，查询已知，8类记忆。新RNG783129+noise，noise2/128，每条件128序列。每个样本另改最后相关持有者，要求答案随之改变。128噪声长度排除原训练序列重复；短样本未做训练去重。本轮不代表独立保留门已训练。

设p为学得的稀疏相关性门，v为内容分布：
0 baseline r=1-p,w=p；
1 uniform r=.99,w=p；
2 partial r=1-.5p,w=p；
3 suppress r=1-p,w=p²；
4 exact rejection w=(p>=.5?p:0),r=1-w。

5种子×2长度×128共1280原答案及1280更新答案，每个mode0/2/3/4均全正确。mode1短原答案65..95/128、长74..128/128；短更新77..108/128、长78..128/128。Baseline逐例与原Net软输出一致。无训练参数变化所以只因果干预更新公式，不能声明最佳可训练架构。

状态总质量：baseline/exact rejection始终1；partial约1.90..1.92；p²长条件约.893..998；uniform短3.86..4.29、长.0127..0387。后3种非归一概率，故没有直接使用-log(m[target])比较CE。准确率全对不意味着状态数值健康或任意长度稳定。

结论：支持无关输入不应触发统一旧记忆衰减；精确拒绝弱写入可保持归一化。不能宣称独立衰减门优于原耦合门，因为baseline已满分且其余内容相关方案同样满分。半衰减、p平方未表现准确率优势，反而改变幅度。统一.99衰减是未重新训练的负面对照，不能否定所有固定衰减模型。没有多话题槽位、新事实插入不同位置或容量压力测试。
