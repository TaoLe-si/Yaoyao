# 重复旧事实后的选择性衰减压力测试

冻结init_write4_2五种子共享原token权重，非提交辅助监督分支。原事实连续重复1/32/256次，一次明确不同的新持有者，然后256个无关事件。每种子/重复数64个样本，新RNG287111；相同底层样本重复用于各更新公式，非独立随机重复。未重新训练，未做语法变体或多槽位。

mode0原耦合门、mode3弱写入p平方、mode4精确拒绝p<.5，分别960/960更新即时正确且960/960后缀保持正确。原基线已满分，无新方案优越性证据。
mode2保留1-.5p：seed42在32/256重复后仅55/64更新正确，seed7仅39/64；seed2026更新正确但长干扰后58/64。旧内容残留让一次新事实不一定胜出。状态总质量趋于2，不是归一概率。
mode1统一.99旧衰减：重复32/256后全部五种子即时更新0/64，后缀也几乎全错。此为冻结适用于另一更新式的权重之干预，不能否定重新训练的时间衰减模型。
mode3状态总质量长后缀最低约.828，虽然答案正确仍有幅度风险；mode0/4保持1。

解释：半衰减r=.5,w=1在重复相同理想内容时质量趋于2；一次新写入后旧内容~1，新内容1，接近打平，小数值误差便影响赢家。不是“新事实不够多”，而是更新规则没有赋予一次明确替代足够力度。

决定：暂不采用削弱相关更新衰减的方案。保留相关时足够替换、无关时精确保持；输入衰减与旧事实替换分开理解。独立r/w门训练、容量压力和真实文本未验证。当前实验未证明比现有耦合门更好，不能为提出新机制而增加参数。

主要输出test_decay_repetition.cpp；原test_content_decay.cpp基线未修改。C++17 MSVC14.44 /O2运行。未改正式模型。后续更有价值的是检验弱相关门失误的长累积与可校准拒绝区，而非再减少旧事实替换幅度。
