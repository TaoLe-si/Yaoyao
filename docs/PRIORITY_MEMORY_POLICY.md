test_priority_memory.cpp为确定性四槽位字典，不是训练模型。输入key/value/important已结构化，重点标记是额外信息。普通策略按写入时间淘汰；重点策略先淘汰最旧普通项，满重点且新项普通则拒绝，满重点且新重点则淘汰最旧重点。同key更新值并继承重点，clear_priority显式取消。没有TTL或频率阈值，不是0.01%频率衰减测试。

256次不同value参数化单元测试，不是256独立学习实验：128无关新key后普通策略保持0/256、重点策略256/256。无标记同key更新再128干扰，重点策略256/256保持新值。未标记旧项均淘汰；取消重点后可淘汰。5重点超过4槽只保留4条，最旧重点淘汰，明确容量边界。
