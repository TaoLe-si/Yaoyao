# NLL瓶颈原因报告（当前试验不中断）

已证实/高置信：
1. 训练语料范围错误：此前模型反复训练2015篇、65.7万BPE token；约3000万参数对应监督token/参数仅约0.0133，重复epoch导致训练NLL下降而验证泛化停滞。
2. 冻结1200模型存在巨大匹配评估差距：长度分层训练样本NLL约3.386，而固定验证6.648，说明不是单纯验证滞后。
3. 原训练顺序固定且每步有效监督量波动4.46倍，TBPTT 256并跨chunk携带状态，顺序/状态分布会放大振荡。
4. 量化训练使用三值投影/STE，支持集合离散；有效权重变化不连续，容易出现训练loss继续降而验证改善有限。

已证伪或未证实：CUDA捕获空白批次污染未发现源码路径；GPU固定验证与CPU结果一致；游标完整覆盖，无截断/漏文档证据；不能把单次shuffle收益归因于唯一原因。

当前修复路径：扩展至29498篇、5610645监督token，确定性epoch洗牌，保持正式验证口径，每个GPU更新后验证，并提供已验证可恢复检查点。扩展试验结束前不宣称解决；若40步改善，仍需更长、曝光匹配的受控确认。
