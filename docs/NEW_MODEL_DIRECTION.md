## Data contract proposal
Maphuman->user,gpt->assistant;unknown roles quarantine instead of guessing. Explicit role/turn/sample boundaries;preserve case/newlines/punctuation;byte-fallback subword tokenizer with special token escaping. No numeric special IDs until tokenizer specification fixed. SFT loss on assistant content+assistant turn terminator;sampleEOS explicitly supervised when appropriate,not silently omitted. Inputs shifted targets+1 with mask aligned to target positions. User/system conditioning updates model state even when loss masked. Packing unrelated samples resets ALL recurrence/local windows and masks cross-sample supervision. Overlength samples must follow documented chunking/truncation policy;do not blindly truncate assistant answers.

Tokenizer fitted only on training partition;group exact/near duplicates before final split;language-balanced metrics,do not assume English-heavy aggregate represents Chinese quality. Infinity is instruction data;from-scratch language foundation adequacy remains unproven. No raw conversion/retokenization/training performed.
