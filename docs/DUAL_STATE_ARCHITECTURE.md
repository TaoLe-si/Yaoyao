## 第二步提案，尚待确认：内容门控更新
所有参数跨时间共享，各层独立。x为当前层输入，s0/m0为上一token状态。

u_s=tanh(W_s x+U_s s0+b_s)
a=sigmoid(W_a x+U_a s0+b_a)
s=s0+a*(u_s-s0)

u_m=tanh(W_m x+U_m s+V_m m0+b_m)
g=sigmoid(W_g x+U_g s+V_g m0+b_g)
m=m0+g*(u_m-m0)
y=x+P_s s+P_m m

*为逐元素乘法，a与s同维、g与m同维。投影P映射回x维度。局部状态不读取m，长期更新读取新s和旧m；层输出交给下一层，不再次写回本层当前token状态。门和候选没有未来输入或人工事件类型。上式尚未含归一化，具体位置/精度/初始化留后续步骤，不能据此宣称规格完整。

重要限制：sigmoid有限值不产生严格零门，重复的小g仍可能慢慢侵蚀m；内容相关不是遗忘免疫。方程选择平滑可训练作为初始取舍，不宣称无关输入必定不更新。若要求严格跳过，必须另外明确两端相同的门函数与梯度策略，不在推理偷偷阈值化。s/m有界仅在初始状态有界和tanh候选/0..1门条件下成立；y残差不因此有界。三值化矩阵/浮点状态和尺度细节待定。
