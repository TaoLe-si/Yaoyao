# 夭夭架构探索：20轮阶段评估

## 决策
保留原token选择性写入备选，并保留“局部构造—预测提交—选择性长期更新”作为优先研究候选。不宣告通用架构已找到。

原备选在已训练语法/已见身份组合中稳定，但严格未见配对仍有种子失败。新候选推理已移除人工类型和边界输入，严格因果；训练仍需边界辅助监督。因此没有在原“仅最终答案监督”条件下证明同等胜出。

## 证据
局部窗口全局求和存在不同最新事实的精确状态碰撞。固定衰减简化实验不代表所有SSM失败。初始化、稀疏门、多样数据有益，但因子化、增强、L2、平滑门、课程和增宽均非普适修复；未拼接各配置的最好种子。

新候选217参数原token边界MLP+1065存储参数记忆网络，5组跨种子组合、3已训练格式、未见身份配对、每侧128干扰：1920原答案和1920关键更新反事实全正确，边界错误0，最终回归复现。原格式32事件多次更新1280/1280正确。

陌生长分隔、反向插入分隔、重复分隔仍失败。四token窗口不是通用语言解析器。查询预先给定，记忆只有8类答案；覆盖非可逆链。无三值QAT、真实文本语言损失或正式模型集成。

## CPU
7940H，MSVC14.44 /O2 /archAVX2，FP64约10KiB权重，逐步无动态分配。最终回归中位0.0656–0.0693微秒/token，不是LLM速度。
稠密FP32替代D4096：只边界43.63微秒；提交1/3、写入1/12时82.95微秒；每步全写233.63微秒。输入已就绪，朴素内核，非三值。
32层仅线性估算1.40/2.65/7.48ms/token，未测缓存竞争。每模块1.5MiB FP32，32模块48MiB。建议少数共享模块、复用特征、不新增大词表内容头。实际提交率和精度未知。
