# 第十五步已批准：正式分词器

确定性字节级BPE，总词表16384。ID0..255原始字节，256BOS，257USER，258ASSISTANT，259TURN_END，260EOS，261..16383为16123个学习合并。无PADtoken，批处理依赖长度/有效位置掩码。

训练分区拟合，用户/助手正文都使用，不读取验证测试。每消息独立编码，合并不跨消息或控制token。保留原字节，不大小写或Unicode规范化、不清理空白。控制token仅由应用插入，用户字面字符串按普通文本处理。相同频次需确定性排序，具体tie-break算法实现规格待明确。存合并表、版本及指纹，两端同产物。当前2015条pilot不作为正式词表拟合全集，正式样本范围尚待一次确定。

助手解码屏蔽BOS/USER/ASSISTANT，不屏蔽TURN_END/EOS；训练损失仍覆盖全词表。字节输出缓冲未完成UTF8，结束时非法序列需明确处理，不宣称模型生成必合法。

已批准到第15步；核心架构不再新增分支。下一阶段是完整规格收束与GPU训练/CPU解码接口，不运行符号补测、不CPU训练。
