# Continuous training driver

Replaces process-per-update with GPU-resident loop. Same100step budget, LR identity, data order,4slots8accum and256block. Saves every10updates/end/STOP boundary to separate continuous filenames. No implicit epoch reset or optimizer changes. On error last disk checkpoint survives, up to9updates may be lost; not fault tolerant. No GPU training launched this round; nvcc/MSVC compile passed only. CPU init still performed once before loading checkpoint. External runner holds shared exclusive lock, detects both executable names, writes one bounded-per-step log, refuses existing STOP. Cannot guarantee child cancellation on terminal destruction; safe stop file preferred. Existing single-step runner remains legacy, use new run_continuous_training.ps1 instead. Runtime integration not yet verified. Latest confirmed modelstep31 unchanged.
