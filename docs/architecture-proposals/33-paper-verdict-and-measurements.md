## 零、三项新实测（本机，零训练）

### 实测 1：M 的秩在 ~120 token 就饱和到恰好 64 = min(dv,dk)

工具：`build/state_probe.exe MODEL.dsb TEXT.txt [MAXTOK] [EVERY]`（新建，Jacobi 特征分解量奇异值谱）。
模型：交付模型 `build/s2_night1/final.dsb`。输入：真实 held-out alpaca 文本。

```
POS   LAY  ||M||_F   sv_max   rank(1e-3)  stableRank
   40    0   506.17   217.81       33         5.40
   80    0   622.35   270.23       61         5.30
  120    0   705.90   280.35       64  <-- 饱和  6.34
 1500    0  1649.83   498.13       64        10.97
 1500    1   858.06   325.40       64         6.95
```

**秩上限 = min(dv,dk) = min(512,64) = 64，实测在约 120 个 token 就触顶。**

### 实测 2：真实文档长度 >> 120 token，故 M 在文档大部分区间已满

从 `build/s2_night1.log` 的 SHARD_LOADED 行统计（平均 token/文档）：

| 阶段 | 分片 | 文档数 | 平均 token/文档 | 秩饱和(120)占比 |
|---|---|---:|---:|---:|
| 维基 | 0–12 | 20,000 × 13 | **701–724** | **约 83%** |
| 真实推理 | 13–16 | 48,400 × 4 | **96.4–96.9** | 约 20% |
| alpaca | 17–24 | 23,853–24,000 | **161.6–164.4** | 约 26% |

### 实测 3：‖M‖_F 单调无界增长（无衰减项的直接证据）

同一 1500 token 序列：`‖M‖_F` 层 0 从 **755 → 1650（2.2 倍）**，`sv_max` 从 **287 → 498**，
`stableRank` 从 6.9 → 11.0，`top10svfrac` 从 0.67 → 0.47（能量摊平）。
**没有任何饱和或衰减的迹象。** 由于 `o = M q`，读出尺度上界 `‖o‖ ≤ sv_max·‖q‖` 随之增长。

## 一、对 doc 32 的两处更正

### 更正 A：delta 规则**已经是** CEC 的矩阵版（我 doc 32 §二 表述过强）

xLSTM 校正稿指出，把我们的内核展开：

```
M_t = M_{t-1}(I - beta * khat khat^T) + beta * v khat^T
J   = dM_t/dM_{t-1} = I - beta * khat khat^T
   特征值 = 1 (重数 dv-1=63) 与 1-beta (重数 1)
```

我用 2000 次随机探测做了数值验证：

```
正交补方向  ||J w||/||w|| = 1       命中 2000/2000
平行方向    ||J w||/||w|| = 1-beta  命中 2000/2000  (beta=0.7 -> 0.300)
```

**这正是 LSTM97 式 35 要求的恒等误差流 `∂s_t/∂s_{t-1} = 1`** —— 在 63/64 个方向上是严格恒等，
只有被写入的那一维按 `1-beta` 收缩。所以 doc 32 §二 说「M 缺遗忘门」需要限定：
**缺的不是误差流恒等性（它比遗忘门更强），缺的是「主动衰减」通道** —— 
现状下旧内容只能被新写入**挤掉**，不能被**淡出**，这正是实测 3 的范数无界增长的来源。

### 更正 B：`mem.value` 占 47.1% 计算权重，但**不增加 rank**

```
每层计算权重 557,056 (= 1,114,112 / 2) 的构成:
  mem.value       262,144   47.1%   <- 只决定 512 行各自的值，不增加 rank
  s.candidate.x    65,536   11.8%
  s.gate.x         65,536   11.8%
  read.s           65,536   11.8%
  mem.key          32,768    5.9%   <- 真正的 rank 旋钮
  mem.query        32,768    5.9%   <- 真正的 rank 旋钮
  s.candidate.s    16,384    2.9%
  s.gate.s         16,384    2.9%
```

**最贵的张量（占 47%）完全不加容量，最便宜的两个（各 5.9%）才是容量旋钮。**
这是本项目参数分配上最反直觉的一个结构性事实。

## 二、一条「已实现」说明：按文档重置状态已经做了

TFLA 校正稿建议「在域边界/新文档处重置状态」（其论文附录 E.2 的做法）。核对源码：
**这个已经实现了。**

- `src/shuffled_epoch_batch_plan.hpp:17` → `p.items[...] = {..., true, t==0 && w.reset, ...}`（第 4 字段是 reset）
- `src/shuffled_epoch_cursor.hpp:74-77` → 换新文档时 `reset=true`

所以**不需要再做**。这也解释了为什么遗忘是「跨域」而非「跨文档」：状态每次重置，
但**权重**在跨域时被覆盖 —— 与 doc 31 的实测结论一致。

## 三、五篇校正稿的收敛结论

| 问题 | 五篇一致判定 | 依据 |
|---|---|---|
| P1 灾难性遗忘 | **5/5 说不能解** | 门/衰减只作用于**状态**；遗忘发生在**权重**。LSTM97 无域切换实验、DeepSeek 全文 0 次 rehearsal |
| P2 216 KB 容量 | 只能加**状态**，不能加权重 | Mamba Table 10（+1% 参数换 >1.0 ppl，**但需选择性读出**）；xLSTM 的 C 是无参数状态 |
| P3 读出 | **已有 query 读出**，缺的是**尺度归一化** | 实测 3：‖M‖_F 无界增长，而 `o=Mq` 无分母 |
| P4 计数/终止 | **文献公认未解** | LSTM97 §6 原文承认「需外挂计数机制」；五篇至今无设计 |

**新增的独立收敛点**：Mamba 校正稿与 xLSTM 校正稿**各自独立**指出 `rank ≤ dk = 64`，
而实测 1 直接证实了秩恰好在 64 饱和。这是本轮唯一由**两条独立论证 + 本机实测**三方印证的结论。

## 四、修正后的实验优先级

### T1（最高，零架构改动）训练配方：排练 + LR 余弦衰减

- 依据：5/5 一致 —— P1 只能靠数据/优化配方；DeepSeek-V4.1 全程**混合分布 + 余弦衰减**（28T 后 2.6e-4 → 2.6e-5）
- 做法：分片目录改为「每 k 片插 1 片旧域」的**交错顺序**；末段加余弦衰减。`steps_per_shard` 是全局量，
  所以**只改分片目录的硬链接顺序**即可（`build/swap_reason.cjs` 已有此机制）
- 判据：wiki NLL 回退从 **+15.2% 压到 <+8%**，reason/alpaca 增益保留 ≥90%

### T2（次高，~0 参数）衰减门 + 读出归一化 —— 直击实测 3

依据是实测 3 的**无界范数增长**：现状没有任何机制阻止 ‖M‖ 随 token 数线性增长。

    # 只新增两个 640 维投影（w_f, w_i），+1280 ternary = 计算权重的 0.115%
    f = sigmoid(w_f^T [x_n; s] + b_f)      # b_f 初值 +3~6（xLSTM Table 2：取 +inf 会 NaN）
    M <- f ⊙ M                            # 先衰减（Mamba 校正稿强调必须在算 acc 之前）
    acc = <M_i, khat>                     # 再算 delta
    M_i <- M_i + beta (v_i - acc) khat    # 保持现有 delta 残差
    n <- f ⊙ n + beta khat                # normalizer 状态，+64 float = 256 B
    o = M q / max(|n^T q|, 1)             # 尺度不变分母（n 必须有下界 1，TFLA Fig.11）

- **状态代价**：257 KiB → 257.5 KiB（+0.2%）
- **判据**：‖M‖_F 在 1500 token 内不再单调增长（用 `state_probe.exe` 直接复测，**这是最干净的判据**）；
  跨注入颜色命中率 0/12 → ≥4/12
- 风险：三值权重的 exp 门数值风险高。**建议先用 sigmoid 门**（TFLA 实测 mLSTMsig 与 exp 门性能相当：
  21.03 vs 21.06、16.66 vs 16.67），避免 max-trick 与溢出

### T3（第三，+11.8% 参数）dk 64 → 128 —— 直击实测 1

- 依据：实测 1 的秩饱和在 64；实测 2 显示维基文档 83% 的区间里秩已满
- 价格：`mem.key + mem.query` 各 64→128 → **+131,072 ternary（+11.8%）**；状态 M 256 KiB → 512 KiB
- 判据：`state_probe` 复测秩饱和点应从 ~120 token **右移到 ~240 token**；维基分片 NLL 应下降
- 注意：Mamba Table 10 警告**只扩状态维而不给选择性读出增益 <0.1**；但我们的读出已有 query，故可试

### T4（P4，独立课题）停止头 + 计数通道

五篇一致确认 P4 是开放问题。xLSTM 校正稿给的可用原语：`n_t^T q` 是
**按 query 对齐度加权的写入次数**（`Σ_i (Π_{j>i} f_j)·i_i·(k̂_i·q)`），
接一个标量输出到停止 logit，**注意它与 T2 共用 n，不额外花运算**。
但 TFLA 校正稿指出张力：α→1 才近似真计数，α<1 才有遗忘 —— **不能指望同一个门同时解决 T2 与 T4**。

## 五、明确的负面清单（不要做）

| 不做 | 理由 |
|---|---|
| KV cache / MLA / FP4 KV / SWA Bounded Replay / 稀疏 indexer / CED / MoE | 全是 Transformer/注意力专属；我们无 KV cache（状态定长 257 KiB）|
| TFLA 分块并行 / selective scan 融合 / HBM↔SRAM 分层 | 状态才 257 KiB，本就装得进 SRAM；论文自己是 H100 + dhv=512 + 7B 的结论 |
| chunkwise 并行训练公式（物化 T×T） | 我们逐 token 自回归，引入只增复杂度与数值风险（论文记录 xl_chunk 有不可恢复 spike）|
| 逐元素对角门控读出 `o_j = c_j m_j` | Mamba 附录 A 点名：只是 GLU，trivial transformation，**不构成内容寻址** |
| 把 m 换成矩阵 + `o = M q` | **已有**，属重复建设 |
| sLSTM 的 memory mixing R（block-diagonal d²/Nh） | d=512 时四门需 131,072 权重 = 计算权重的 11.8%，性价比不足 |
| 「在域边界重置状态」 | **已实现**（§二）|

## 六、关于「遗忘动门能不能救 P1」的最终态度

**不能，五篇一致。** 但请注意 P1 与实测 3 的区别：

- **P1（权重遗忘）**：实测 +15.2%，机制是跨域梯度覆盖共享权重。**只能靠 T1（数据/优化配方）**。
- **实测 3（状态无界增长）**：是**状态**问题，靠 T2 修。

xLSTM 校正稿给了一条可检验的**间接**链条（标注为推断）：M 无衰减 → 持续累积饱和 → 
梯度压力被推回权重 → 加剧权重漂移。**若成立，T2 会小幅改善 P1。** 这是可证伪的：
T2 落地后复测 wiki 回退，若从 +15.2% 降到 <+10%（但未到 <+8%），则间接链条部分成立。
